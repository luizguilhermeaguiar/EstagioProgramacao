# 💻 Estágio de Programação

## 📌 Sobre o projeto

Este repositório documenta minha jornada de desenvolvimento como programador por meio de um estágio prático simulado, utilizando Python como linguagem principal.

O projeto tem como objetivo consolidar fundamentos de programação, desenvolver raciocínio lógico, aprimorar a capacidade de resolver problemas e aprender boas práticas utilizadas no desenvolvimento de software.

O estágio é conduzido por meio de demandas progressivas, exercícios práticos, projetos e avaliações técnicas.

## 🎯 Objetivos

- Consolidar os fundamentos de Python.
- Desenvolver autonomia na resolução de problemas.
- Aprender a escrever código organizado, legível e sustentável.
- Praticar estruturas de dados, funções e lógica de programação.
- Desenvolver projetos aplicados a situações reais.
- Aprender a utilizar Git e GitHub para versionamento e organização de código.

## 🛠️ Tecnologias e ferramentas

- **Python:** linguagem principal.
- **Git:** controle de versão.
- **GitHub:** hospedagem do repositório e acompanhamento da evolução.
- **Visual Studio Code:** ambiente de desenvolvimento.

## 📁 Estrutura do repositório

```text
Estagio-Programacao/

├── entregas/
│   └── semana-01/
│       └── desafio-01/

```

A estrutura será expandida conforme o avanço do estágio e o surgimento de novas demandas.

- `entregas/`: exercícios e desafios técnicos.
- `projetos/`: projetos desenvolvidos durante o estágio.
- `estudos/`: anotações, conceitos e registros de aprendizado.

## 📚 Metodologia

O estágio será desenvolvido em etapas progressivas, respeitando o nível de conhecimento demonstrado nas entregas.

Cada demanda poderá incluir objetivos, requisitos, critérios de aceitação e avaliação técnica.

O foco não será apenas produzir código funcional, mas também compreender as soluções implementadas, identificar erros e desenvolver autonomia.

## 📈 Acompanhamento

O progresso será acompanhado por meio das entregas realizadas, das avaliações técnicas e da evolução dos projetos.

Os desafios serão ajustados conforme as dificuldades identificadas e o domínio dos conteúdos.

## 🚀 Objetivo de longo prazo

Desenvolver um sistema de controle de vendas em Python, aplicando progressivamente os conhecimentos adquiridos durante o estágio.
